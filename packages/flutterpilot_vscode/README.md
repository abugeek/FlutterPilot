# FlutterPilot for VS Code

VS Code extension for FlutterPilot.

## Features

- **Dashboard**: Integrated webview to monitor FlutterPilot status.
- **Server Management**: Commands to start and stop the MCP server.
- **Screenshots**: One-click screenshots of your running app.

## Commands

- `FlutterPilot: Start MCP Server`
- `FlutterPilot: Capture Screenshot`

## Development

To compile the extension:

```bash
melos run vscode:compile
```
